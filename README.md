## General Principles

The Ryoeh Proprietary License is based on the following principles:

- **Public inspection:** Published source code may be viewed and studied.
- **Reserved rights:** Access does not automatically grant permission to reuse, reproduce, modify, or redistribute the Software.
- **Prior authorization:** Uses beyond the permissions expressly granted require prior written authorization.
- **Commercial restrictions:** Commercial use requires explicit authorization.
- **Third-party materials:** Components owned by third parties remain subject to their respective licenses.

These principles are a general overview, not a substitute for the complete legal text of the applicable version.

Projects adopting the Ryoeh Proprietary License should:

1. Include the applicable license text in the repository.
2. Clearly identify the exact license version being adopted.
3. Specify which files or materials are covered.
4. Preserve relevant copyright and ownership notices.

The presence of a link to this repository alone should not be treated as a substitute for identifying the applicable license version and scope.
